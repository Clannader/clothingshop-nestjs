# 发布包版本步骤

---

## 1. 发布流程

1. 使用 dev 分支打 tag，上传到 github，通过 github 生成 release note 和 release 分支
2. 进行打包生成最新代码
3. 删除 `package.json` 的 `private`、`devDependencies`、`jest` 节点
4. 删除 `package.json` 的 `scripts` 中的其他节点，只保留 `publish:npm` 和 `start` 节点
5. 运行 `publish:npm`，如果有报错使用 cmd 运行以下命令重新登录验证，再次运行 `publish:npm`

```bash
npm login
```

6. 撤回刚才修改的 `package.json`，修改 `package.json` 的版本号到下一个版本
7. cmd 运行以下命令更新 `package-lock.json`，然后提交代码即可

```bash
npm uninstall all
```

## 2. 测试打包

1. 在package.json中添加

```json5
{
  "files": [
    "build",
  ]
}
// 这样就可以限定打包哪些文件了,默认会加上package.json,README.md,LICENSE等文件
// 这样就不需要设置.npmignore了
```

2. 测试打包的产物

```bash
npm pack
// 运行后会在当前目录生成一个 tar 包,可以解压查看打包的产物
```
